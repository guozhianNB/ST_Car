# MS42CG 独立平衡台架：接线、验证与调参

最后更新：2026-08-01。本手册对应 MS42CG + 普菲德 TB6600 光耦驱动器版本；旧 P60/TB6612/SA100 命令已经失效。

## 1. 不可跳过的安全门禁

每次可能产生输出前确认：

1. 车轮悬空，钢球移除；
2. 首次摆杆测试连杆脱开，或曲柄已确认不可能进入死点；
3. 首次烧录/测波形时，底盘 STBY 和步进 EN 与 MCU 线隔离，并在驱动侧可靠下拉到 GND；
4. 电机电源、逻辑电源、NUCLEO、MaixCAM2、TB6612、步进驱动器共地；
5. 电源极性、稳压输出、STEP/DIR/EN 和编码器电平已用万用表/示波器确认；
6. 操作者可立即切断电机主电源。

不能同时首次上电三个电机；不能在编码器方向/有效性未知时闭合滚球环；不能关闭堵转、视觉超时或 EN 安全逻辑来“试一下”。

## 2. 台架串口

ST-Link VCP / LPUART1，115200 8N1。正常应用必须在 standby 才能执行：

```text
bench on
help
status
```

PC13 在台架激活时为急停。任何异常同时按 PC13 并切断电机主电源；软件急停不能替代物理断电。

## 3. 命令

| 命令 | 作用 |
|---|---|
| `bench on` / `bench off` | 进入/退出台架；底盘保持禁用 |
| `run <signed_steps_s> <ms>` | 限时开环步频：绝对值≤100 steps/s、最长500 ms且命令脉冲预算≤10；`run 200 500` 会被拒绝 |
| `zero` | 清 TIM4 调试累计计数；不定义中点、不影响控制 |
| `diag reset` | 清步频积分和正/负运行时间统计 |
| `ball <mm>` | 启动视觉单环位置控制，最长 30 s |
| `ball sequence` | 执行 `0 -> +50 -> -50 mm` |
| `gain ball <kp> <ki> <kd> <sign>` | 只改 RAM 中视觉 PID |
| `gain accel <ka>` | 只改 RAM 中视觉加速度项 |
| `limit rate <steps_s>` | 设置闭环步频上限，不超过 1800 |
| `status` | 单次状态 |
| `stream on [ms]` / `stream off` | 连续状态，周期 20..2000 ms |
| `stop` / `clear` | 停止输出/清台架故障 |

主要状态字段：`enc/denc` 为执行器编码器原始计数，`sreq/sapplied` 为步进驱动层请求/实际频率，`crate` 为控制层斜坡后频率，`pid/integ` 为 steps/s，`ball/vball` 为 mm 和 mm/s，`vs=1` 才是真测量。

## 4. 分阶段验证

### A. 只测 MCU 波形，不接驱动器

TB6600 主电源保持断开；PUL+/DIR+/ENA+ 接 3V3，三个负端暂不接 MCU。先测 MCU 引脚，再按共阳合同接入负端。执行：

```text
bench on
run 200 200
run -200 200
stop
```

示波器验证 PB14：约 200 Hz、50% 占空比；PC4 在正负命令间改变；改变 DIR 前 STEP 已停止至少 1 ms；PC5 在动作期间为高，停止/台架退出/急停后为低。接入 TB6600 信号端后，还要测得 PC5 低时 ENA 光耦有效、驱动器脱机，PC5 高时才运行。PA10、PB1 始终低。保存测量值后才能接主电源与电机。

### B. 驱动器与电机脱连杆低速

先按驱动器手册设置相电流为电机允许值或更低的保守起点，细分先选定并记录。只接 MS42CG，连杆脱开：

```text
run 100 100
run -100 100
status
```

确认方向、声音、电流、温升、EN 停止语义。若正负方向不符合机构定义，只改 `APP_STEPPER_DIRECTION_SIGN`；不要交换软件各处符号。电机只抖不转时，断电后检查 A/B 两个线圈对、相序、限流和细分，不能直接提高电压或频率。2026-08-01用户已将 SW1/SW2/SW3 设为 OFF/OFF/ON，并用受限点动确认16细分、3200 pulses/rev。该档下 `run 100 50` 只有约3.75个实际脉冲，可能不足以克服机构回差，不能用它单独判定反向失步。

### C. 编码器

`VERIFIED（用户实测，2026-08-01）`：正命令方向为顺时针并抬高水管，该方向手转一圈的 TIM4 原始计数为 `-4096`。固件已设置 `APP_ENCODER_ACTUATOR_SIGN=-1`，因此执行 `zero` 后沿正命令方向手转一圈，遥测 `enc` 应约为 `+4096`；反向一圈应约为 `-4096`。还需补做正反各三圈，确认重复性、停止后 `denc=0` 和16位回绕无跳变。

当前堵转门限暂定为绝对步频至少 32 steps/s 且连续 750 ms 无计数变化。必须先采集正常运动和人为堵转数据，证明编码器在该频率范围内能可靠反映步进电机运动，才能依赖该保护。

### D. 空管/脱球机构

保持钢球移除，连杆首次接入前断电并避开死点。使用 `run 100 50` 级别的短命令确认机构正反方向、保持转矩、急停和机械干涉。一次只改步频或时间之一，记录电源电压、相电流设定、细分、指令频率、编码器变化和机械状态。

### E. 固定小车视觉检查

电机保持禁用，固定小车，分别把球放在 `-100、0、+100 mm`，验证视觉符号、误差和真实帧时间。制造 `status=2`、丢球和断开 UART 情况，确认它们不刷新球速/测量时间；超过 150 ms 时 STEP 请求必须归零。

### F. 最低限幅视觉闭环

完成 A-E 后才放球，小车保持静止，先执行：

```text
bench on
limit rate 100
gain ball 2 0 1 -1
ball 0
stream on 50
```

若球位误差增大，立即急停并断电，先检查 `APP_BALL_CONTROL_SIGN` 与机械方向。确认是负反馈后才逐步增加 `Kp` 和 rate limit；出现振荡先降低输出上限和增益。`Ki` 最后启用，`Ka`/加速度前馈最后启用。

### G. 要求 3

球在 O 点且视觉为新鲜 `status=1` 后执行 `ball sequence`。保存完整串口记录，验收 `+50 mm` 首次进入窗口、`-50 mm` 连续稳定时间、总用时、最大步频、丢帧和急停行为。只有该阶段通过后才做低速组合循迹。

## 5. 必须写回的实测值

记录到 `docs/measurements/ms42cg-stepper-migration-2026-08-01.md`：驱动器准确型号/版本、供电、相电流、细分拨码、EN 极性、逻辑高低电平、相线线序、编码器供电/输出类型/每圈计数、方向 sign、最低可靠步频、最大安全步频/加速度、堵转阈值和视觉 PID。

台架 RAM 命令不会自动写回 `app_config.h`。每次只写回有日期、条件、单位和原始记录支持的参数。
