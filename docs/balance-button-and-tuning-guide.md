# 双按钮与 MS42CG 视觉单环调参指南

最后更新：2026-08-01。单位统一为 mm、mm/s、ms、degree 和 command steps/s。

## 按钮

- PA4 短按：正方向 `200 steps/s、60 ms` 调平试动；长按 1 s 启动要求 3。
- PA15 短按：负方向同规格调平试动；长按 1 s 捕获最新真实球位并启动保持。
- PC13：启动/停止；台架模式中是急停。

短按直接驱动步进机构，不再修改 SA100 零点。短按方向由 `APP_LEVEL_UP_STEPPER_SIGN` 集中决定，必须在脱球、低速、可立即断电条件下确认。

## 调参顺序

1. 按台架手册确认 STEP/DIR/EN、相线、限流、细分和编码器。
2. 空管确认 `APP_STEPPER_DIRECTION_SIGN`。
3. 固定小车确认视觉 `-100/0/+100 mm` 和 `APP_BALL_CONTROL_SIGN` 形成负反馈。
4. 将闭环上限降到 100 steps/s，`Ki=Ka=0`，先调很小的 `Kp`。
5. 逐步增加 `Kp` 到能克服机构与球的迟滞；出现持续往返就回退。
6. 增加 `Kd` 抑制真实球速导致的超调；视觉速度噪声大时不要过度增加。
7. 仅在存在可重复静差且方向/摩擦已确认后加很小 `Ki`。
8. 加速度项与更高的步频/加速度上限最后启用。

每次只改一个层级并保存：目标、视觉位置/速度、PID steps/s、实际 STEP 频率、周期、电池/驱动电压、相电流、细分和机械状态。参数能编译不等于已调好。

## 视觉有效性

只有 `status=1` 推进 PID、积分与球速微分。`status=2` 只表示 MaixCAM2 保持旧值；`status=0` 无效。真测量超过 150 ms 时固件立即停止 STEP，但在活动保持态仍可能保持 EN 高以提供静态转矩；急停、待机和故障会同时拉低 EN。

## 常见故障

| 现象 | 先检查 |
|---|---|
| 电机只抖不转 | 断电后核对两个线圈对、A/B 相序、限流、细分与 STEP 波形 |
| 命令正负方向相反 | 只改 `APP_STEPPER_DIRECTION_SIGN` |
| 一闭环球就加速离开目标 | 立即急停；核对视觉坐标和 `APP_BALL_CONTROL_SIGN` |
| 低速不动或失步 | 驱动器限流、机械死点、加速度、最低可靠步频；不要先关闭保护 |
| 误报堵转 | 先确认编码器供电/电平/方向/计数，再基于数据调阈值 |
| 视觉保持值仍在变化控制 | 检查协议两端；`status=2` 不能生成新测量 |
| 急停后仍有保持力 | PC5/EN 极性或接线与当前高有效合同不一致，立即断主电源 |
