# NUCLEO-G491RE 引脚、外设与中断分配

本表是 `ST_Car.ioc`、`Core/Inc/main.h` 和实际接线之间的唯一布线合同。更换引脚时必须同时修改这三处，并重新做悬空上电检查。所有 NUCLEO、MaixCAM2、TB6612 和传感器必须共地。

## 定时器与通信资源

| 功能 | STM32 资源 | 引脚 | 配置 |
|---|---|---|---|
| 左 P30 PWM | TIM1_CH1 | PA8 | 20 kHz，PWM1 |
| 右 P30 PWM | TIM1_CH2 | PA9 | 20 kHz，PWM1 |
| P60 PWM | TIM1_CH3 | PA10 | 20 kHz，PWM1 |
| 左轮编码器 A/B | TIM2_CH1/CH2 | PA0/PA1 | TI12，32 位计数，输入滤波 4 |
| 右轮编码器 A/B | TIM3_CH1/CH2 | PA6/PA7 | TI12，16 位计数，输入滤波 4 |
| P60 编码器 A/B | TIM4_CH1/CH2 | PB6/PB7 | TI12，16 位计数，输入滤波 4 |
| SA100 PWM | TIM15_CH1 | PB14 | PWM Input；1 us 计数；CH1 周期、CH2 高电平 |
| MaixCAM2 | UART4 TX/RX | PC10/PC11 | 115200 8N1；RX 为 DMA1_CH1 环形 DMA + IDLE |
| ST-Link VCP 调试 | LPUART1 TX/RX | PA2/PA3 | 115200 8N1；非阻塞遥测；台架调试开启时 RX 单字节中断接收命令 |
| OLED 预留 | I2C1 SCL/SDA | PB8/PB9 | 400 kHz；显示屏型号确定后补适配层 |
| MPU6050（可选） | I2C3 SCL/SDA | PC8/PC9 | 400 kHz；不参与当前 H 题闭环 |

注意：P30/P60 的 `390/780 counts/rev` 是在“最终定时器 TI12 模式下仍需实测”的暂定值。程序不会再额外乘四。

## TB6612 与普通 GPIO

| 功能 | 引脚 | 上电电平/说明 |
|---|---|---|
| 左电机 IN1 / IN2 | PC0 / PC1 | 低 / 低 |
| 右电机 IN1 / IN2 | PC2 / PC3 | 低 / 低 |
| P60 IN1 / IN2 | PC4 / PC5 | 低 / 低 |
| 底盘 TB6612 STBY | PB0 | 默认低，软件通过检查后才拉高 |
| P60 TB6612 STBY | PB1 | 默认低，软件通过检查后才拉高 |
| NUCLEO LD2 | PA5 | 状态指示 |

左右 P30 共用一块双通道 TB6612；P60 使用第二块 TB6612 的一个通道。若实物板把 STBY 硬件拉高，必须拆除该固定拉高或确认上电安全，软件不能在这种接法下保证复位零输出。

## 循迹与按键

八路循迹从车头朝向看按“最左到最右”排序：

| 序号 | 引脚 | 默认极性 |
|---:|---|---|
| 0 | PB10 | 低表示黑线 |
| 1 | PB11 | 低表示黑线 |
| 2 | PB12 | 低表示黑线 |
| 3 | PB13 | 低表示黑线 |
| 4 | PB15 | 低表示黑线 |
| 5 | PC6 | 低表示黑线 |
| 6 | PC7 | 低表示黑线 |
| 7 | PC12 | 低表示黑线 |

循迹输入由 10 ms 任务采样，不使用 EXTI。模块若是高电平检测黑线，只改 `APP_LINE_ACTIVE_LEVEL`，不要逐处反相。

| 输入 | 引脚 | 触发方式 | 说明 |
|---|---|---|---|
| 启动键 B1 | PC13 | 上升沿，内部下拉 | NUCLEO 板载蓝色按钮，按下为高 |
| 模式键 | PA4 | 下降沿，内部上拉 | 外接按键到 GND |
| P60 中点参考开关 | PA15 | 下降沿，内部上拉 | 外接开关到 GND；必须装在安全中点而不是曲柄死点 |

PA13/PA14 保留 SWD。SYS 使用 Serial Wire，不占 PB3。PC14/PC15、PF0/PF1 保留板级晶振焊盘，即使当前系统时钟实际使用 HSI+PLL 170 MHz，也不应随意接线。

I2C1/I2C3 为 400 kHz，必须确认模块自带或外接合适的 3.3 V 上拉（常用 2.2–4.7 kΩ）；不能依赖 MCU 的弱内部上拉保证总线时序。

## 中断优先级

数值越小优先级越高：

| 中断 | 优先级 | 用途 |
|---|---:|---|
| TIM1_BRK_TIM15 | 1 | SA100 周期捕获 |
| DMA1_Channel1 | 2 | UART4 RX DMA |
| UART4 | 2 | 视觉 IDLE/错误事件 |
| EXTI4、EXTI15_10 | 5 | 模式、启动、中点参考开关 |
| LPUART1 | 6 | 调试遥测发送完成及台架命令接收；接收 ISR 只入队，不解析命令 |
| SysTick | 15 | 1 ms HAL 时基和主循环调度 |

编码器不使用更新中断；通过固定位宽的回绕安全差分读取。循迹不使用 GPIO 中断。中断回调只更新时间戳、数据快照或事件标志，不在 ISR 中运行 PID、字符串输出或阻塞 I/O。

## 上电前接线检查

1. 架空三个电机或拆下连杆，万用表确认 PB0/PB1 复位时为低。
2. 确认电机电源为 11.1 V 电池、逻辑电源符合模块额定值，并共地。
3. 确认 MaixCAM2 TX 接 PC11（STM32 RX）；PC10 仅在需要 STM32 回传时连接 MaixCAM2 RX。
4. SA100 输出必须是 3.3 V 兼容电平；若为 5 V 输出，先确认该具体引脚的容限并优先做电平转换。
5. P60 上电时必须处于机械安全中点且水管接近水平。没有可靠参考开关时，启动键代表人工确认当前中点，软件随后把 P60 增量计数清零。
6. 首次烧录保持 TB6612 STBY 断开，先检查 PWM 频率、方向 GPIO 和编码器计数，再接驱动使能。
