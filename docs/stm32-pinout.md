# STM32G491RE 引脚、定时器与接线合同

最后更新：2026-08-01。本文必须与 `ST_Car.ioc`、`Core/Inc/main.h` 和 HAL 初始化保持一致。

## 1. 定时器

| 功能 | 定时器 | MCU 引脚 | 当前配置 |
|---|---|---|---|
| 左轮 TB6612 PWM | TIM1_CH1 | PA8 | PWM1，20 kHz，复位比较值 0 |
| 右轮 TB6612 PWM | TIM1_CH2 | PA9 | PWM1，20 kHz，复位比较值 0 |
| MS42CG 驱动器 STEP | TIM15_CH1 | PB14 | PWM1，1 MHz 定时器计数；运行时改变 ARR，50% 占空比 |
| 左轮编码器 A/B | TIM2_CH1/CH2 | PA0/PA1 | TI12，32 位，滤波 4，上拉 |
| 右轮编码器 A/B | TIM3_CH1/CH2 | PA6/PA7 | TI12，16 位，滤波 4，上拉 |
| 步进执行器编码器 A/B | TIM4_CH1/CH2 | PB6/PB7 | TI12，16 位，滤波 4，上拉；仅堵转/调试 |

`PB14/TIM15_CH1` 已从旧 SA100 输入捕获改为 STEP 输出；TIM15 不启用中断。`PA10/TIM1_CH3` 已退出 PWM，固定作为低电平安全锁。正式滚球链不读取 SA100。

## 2. 输出 GPIO

| 功能 | 引脚 | 复位/待机状态 |
|---|---|---|
| 左轮 TB6612 IN1/IN2 | PC0/PC1 | 低/低 |
| 右轮 TB6612 IN1/IN2 | PC2/PC3 | 低/低 |
| 底盘 TB6612 STBY | PB0 | 低；通过启动状态机后才允许拉高 |
| 步进驱动器 DIR | PC4 | 低 |
| 步进驱动器 EN | PC5 | 低；当前合同为高电平使能 |
| 旧 P60 PWM 安全锁 | PA10 | 始终低，不接新驱动器 |
| 旧 P60 STBY 安全锁 | PB1 | 始终低，不接新驱动器 |
| 状态 LED | PA5 | 低 |

`VERIFIED（用户照片，2026-08-01）`：实物为普菲德 TB6600 光耦驱动器。采用下面的 3.3 V 共阳接线时，PC5 低会使 ENA 脱机光耦导通、驱动器关闭；PC5 高会释放脱机、驱动器运行。因此软件中的“高有效使能”与实物端子的“低有效脱机”并不矛盾。

## 3. 输入与通信

| 功能 | 引脚/外设 | 配置 |
|---|---|---|
| 循迹 0..4 | PB10/PB11/PB12/PB13/PB15 | 输入上拉，默认低表示有效 |
| 循迹 5..7 | PC6/PC7/PC12 | 输入上拉，默认低表示有效 |
| MaixCAM2 TX -> STM32 RX | PC11 / UART4_RX | 115200 8N1，循环 DMA + IDLE |
| STM32 TX -> MaixCAM2 RX | PC10 / UART4_TX | 115200 8N1 |
| ST-Link VCP | PA2/PA3 / LPUART1 | 115200 8N1，台架命令/遥测 |
| OLED | PB8/PB9 / I2C1 | 地址运行时探测 0x3C/0x3D |
| IMU 预留 | PC8/PA11 / I2C3 | 当前不进入正式控制 |
| 调平上/下按钮 | PA4/PA15 | 输入上拉，按下接 GND |
| NUCLEO 用户键 | PC13 | EXTI，上升沿；启动/急停 |
| SWD | PA13/PA14 | 保留，不复用 |

UART4 RX DMA 为循环模式，DMA1 Channel 1；UART4 IRQ 优先级 2，DMA IRQ 优先级 3，EXTI15_10 优先级 5，LPUART1 优先级 6。TIM15 STEP 不需要 IRQ。

## 4. NUCLEO 接头定位

按 ST 官方 NUCLEO-G491RE 用户手册的 Morpho/Arduino 映射：

- PB14：CN10-28，连接 STEP；
- PC4：默认可由 CN10-34 引出，连接 DIR；
- PC5：默认可由 CN10-6 引出，连接 EN；
- PB6：CN10-17，连接编码器 A；
- PB7：CN7-21，连接编码器 B；
- GND：从任一明确标注的 NUCLEO GND 引出。

板载焊桥会影响 PC4/PC5 的实际接头映射。接线前必须按手中板卡版本、丝印和万用表通断档复核，不能只凭 Arduino `D0/D1` 名称猜测。

## 5. MS42CG 与普菲德 TB6600 接线合同

MS42CG 是两相步进电机，不能接 TB6612。照片所示 TB6600 的六个信号端从上到下为 `ENA-、ENA+、DIR-、DIR+、PUL-、PUL+`。本项目使用 **3.3 V 共阳**：

| NUCLEO | TB6600 端子 | 说明 |
|---|---|---|
| 3V3 | PUL+、DIR+、ENA+ | 三个正端并联；这里只是光耦信号电源 |
| PB14 | PUL- | 低有效光耦脉冲；PWM 频率仍是一微步一周期 |
| PC4 | DIR- | 方向；最终机械 sign 实测后集中修改 |
| PC5 | ENA- | 低=脱机， 高=运行；复位低符合安全语义 |
| GND | TB6600 主电源 GND | 系统共地；大电流回路不得穿过 MCU 细地线 |

不要把三个信号负端并到 GND，也不要使用共阴接法，否则当前 PC5 复位低会让 ENA 光耦无效、驱动器反而保持上电。不要把 `PUL+/DIR+/ENA+` 接 5 V 后再把负端直接接 STM32：GPIO 高电平只有约 3.3 V，光耦两端仍可能留有压差并导致不能可靠关断。

照片下方 `VCC/GND` 是明确标注的 **DC 9–42 V 主电源端**，不是逻辑电源；VCC 接符合驱动器与电机要求的独立电源正极，GND 接负极。绝不能把主电源 VCC 接到 NUCLEO 3V3/5V。

电机四根相线只能按驱动器的 `A+/A-/B+/B-` 与实测线圈对连接：断电后用万用表找出两个导通线圈对，再结合电机随附线序表确定同相极性。仓库没有可唯一对应本机线色的官方 MS42CG 手册，因此不提供可能错误的颜色表。

编码器 A/B 保留接 PB6/PB7。`VERIFIED（用户实测，2026-08-01）`：正 `run` 命令使电机顺时针旋转并抬高水管；该方向手转一圈的 TIM4 原始变化为 `-4096 count/rev`。软件使用 `APP_ENCODER_ACTUATOR_SIGN=-1`，使遥测中的正命令方向为 `+4096 count/rev`。当前接法已完成功能验证，但编码器供电、输出级和高电平幅度的具体仪表数据仍待补录；禁止把未知 5 V 推挽信号直接接 MCU。

## 6. 首次通电门禁

任何可能产生电机输出的步骤前必须同时满足：

1. 车轮悬空，钢球移除；
2. 首次摆杆测试连杆脱开，或已确保曲柄不可能进入死点；
3. 首次烧录和测波形时，底盘 STBY、步进 EN 与 MCU 线隔离，并在驱动侧可靠下拉 GND；
4. NUCLEO、MaixCAM2、TB6612、步进驱动器和编码器已确认共地；
5. 电源极性、稳压输出、STEP/DIR/EN 与编码器电平已用万用表/示波器确认；
6. 操作者能立即切断电机主电源。

先只给逻辑供电验证：PB0、PB1、PA10、PC5 为低，PA8/PA9 为 20 kHz 零占空比，PB14 无 STEP。之后按单通道、低速、短时顺序逐级接入。
