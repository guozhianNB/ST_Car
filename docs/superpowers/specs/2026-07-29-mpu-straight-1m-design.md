# MPU6050 航向闭环直行 1 m 设计

## 目标

小车上电完成静止校准后，利用现有的编码器测量累计行驶距离，在保持初始航向的同时直线前进 100 cm，达到目标后停车。

## 硬件与坐标约定

- MPU6050 使用软件 I2C：`PC8` 为 SCL，`PC9` 为 SDA。
- MPU6050 竖直安装；其 X 轴角速度代表小车平面偏航角速度。
- MPU 初始航向和后续航向均使用 X 轴陀螺仪积分得到的角度；不使用 Z 轴 yaw。
- 左、右轮编码器的平均位移用于里程。每圈 780 计数，轮周长 20.73 cm；这两个值保留为可调常量。

## 控制流程

1. 初始化电机、编码器和 MPU6050；确认 MPU 的 WHO_AM_I 可通信。
2. 主程序调用 yaw 模块初始化接口；模块保持车辆静止采样校准陀螺仪偏置，并把 X 轴积分角清零。
3. 每 20 ms 执行一次控制循环：
   - 读取两个编码器的增量，以平均值累计距离；
   - 调用 `GetYaw()` 获取 yaw 模块更新后的 X 轴航向角；
   - 将当前 X 轴航向角（目标为 0 度）输入航向 PID；
   - 叠加编码器左右速度差修正与航向修正，得到左右 PWM 输出；
   - 只通过既有 `Motor_SetSpeed(left, right)` 接口驱动电机。
4. 当累计里程达到 100 cm 的容差范围后，连续确认数个控制周期，调用 `Motor_SetSpeed(0, 0)` 停车并复位控制器状态。

## 接口与代码边界

- 在 `main.c` 增加一个单次动作函数，例如 `Car_DriveStraightCm(float target_cm)`；主循环仅调用该函数一次。
- 新增 `yaw.c` 与 `yaw.h`，作为主程序使用 MPU 的唯一入口：
  - `Yaw_Init()`：使用 PC8/PC9 软件 I2C 初始化 MPU6050，完成静止校准，并将 X 轴航向归零；初始化失败时返回失败状态。
  - `GetYaw()`：内部根据 `HAL_GetTick()` 计算时间间隔，读取 MPU6050 并更新 X 轴积分角；返回当前角度（单位：度）。主循环可在每个控制周期调用它，不需要传入 `dt`。
- `mpu.c` 和 `i2c_soft.c` 继续作为 yaw 模块的底层实现；软件 I2C 引脚切换至 PC8/PC9，并使用 STM32G4 HAL 头文件。
- 不修改 `Motor_SetSpeed()` 的语义、不直接配置电机 PWM 寄存器。
- 保留现有 `PID_Control_SetTarget()` 作为编码器左右轮差速修正；航向 PID 在直行控制函数内独立维护，避免更改现有循迹接口。

## 安全与验证

- MPU 不应答或校准期间发生通信错误时，电机保持停止。
- 控制周期异常时回落到 20 ms，防止积分和微分突变。
- 代码验证至少包括：IAR 工程源文件纳入检查、G4 HAL 头文件一致性检查，以及静态检查确保电机控制仅走 `Motor_SetSpeed()`。
- 实车需在架空和低速条件下确认左右正方向、X 轴偏航正方向，以及轮周长和 PID 参数；这些均无法用离线编译替代。
