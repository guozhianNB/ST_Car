# 纯视觉滚球控制重构与实测方案（2026-08-01）

## 1. 目标和不可改变的约束

- 正式反馈只使用 MaixCAM2 的真实球位置和由真实视觉帧得到的球速；不读取管子倾角，不依赖开机管姿态、P60 绝对中点或位置边界。
- P60 编码器仅用于堵转和台架诊断，不能进入正式滚球控制判断。
- 首先完成固定小车的任意目标保持，再完成题目要求 3：`O → +50 mm → -50 mm`，总时间不超过 5 s，两目标最大误差绝对值不超过 10 mm；小车加速度扰动最后处理。
- MaixCAM 屏幕预览保持开启，控制必须容忍实际存在的非均匀视觉帧间隔。

## 2. 已证伪的路线

不能继续把现有控制器当普通二阶位置对象调 `Kp/Kd`。小角度下球杆动力学至少包含：

```text
P60 PWM → 电机/连杆速度 → 管姿态（等效球加速度）→ 球速度 → 球位置
```

标准球杆模型也把球位置、球速度、电机角和电机角速度作为四个状态。部分状态不可测时，研究工作采用状态观测器而不是直接差分噪声信号；参见 [Kim、Park、Choi 2010](https://www.matlabi.ir/wp-content/uploads/bank_papers/g_paper/g145_Matlabi.ir__Sliding%20mode%20control%20designunder%20partial%20state%20feedback%20for%20ball%20and%20beam%20system%202010.pdf)。2021 年 IEEE 实物研究进一步把执行器动态、未知扰动与速度/电流不可测同时纳入观测与主动阻尼：[Kim、Kim、Ahn 2021](https://doi.org/10.1109/TCSI.2020.3032128)。

当前路线的具体不足已经被实测逐项确认：

1. `aball` 是视觉速度的短窗直接差分，没有利用实际 PWM 输入；静止端点仍有 -45.8～+74.0 mm/s² 假加速度。
2. 控制器没有估计执行器速度。主动短刹后仍有约 60～70 P60 count 余动，证明“PWM 变零即管姿态停止变化”的假设不成立。
3. 端点被挡片约束时，静止球位无法区分“刚好水平”和“仍有很大向端点坡度”。这段状态在视觉上不可观，连续 PID 只能不断积累执行器动作，直到球突然高速脱离。
4. 低速脉冲密度线性化只能改善平均输出，不能解决上述状态不可观问题。`rest_max=600 ms` 的反例已记录在 `docs/measurements/visual-pid-2026-08-01.md`。
5. 要求 3 的 50 mm + 100 mm 两段若限速仅 30 mm/s，单匀速时间理论上已经达到 5 s，尚未包含加减速和两次 250 ms 判稳，因此该限速不可能满足比赛时间。

## 3. 选择的控制结构

采用“事件状态机 + 输入感知状态观测 + 三层运动轨迹”，仍属于纯视觉输出反馈，且 PID 最终仍直接给出 P60 PWM 请求。

### 3.1 执行器整形层（5 ms）

- 保留 130～140 PWM 的短脉冲来克服齿轮静摩擦。
- 每个脉冲后强制主动短刹休止；只有休止结束且有新真实视觉测量时才能开始下一脉冲。
- 记录实际输出而不是 PID 请求：正/负累计通电时间、累计 `PWM·ms`、当前脉冲/刹车阶段、最近一次换向时间。
- 先让执行器速度在两次视觉决策之间衰减，暂不直接实现噪声敏感的完整四阶高增益观测器。

### 3.2 输入感知视觉观测器（每 5 ms 预测，每个真实视觉帧校正）

状态至少包含 `v_hat` 和 `a_hat`：

```text
v_hat' = a_hat
a_hat' = b0 * applied_pwm + total_disturbance
```

- 预测必须使用电机实际输出 `applied_pwm`，不能使用尚未执行的 PID 请求。
- 视觉球速只作为带宽受限的校正量；禁止再次用相邻两帧直接相减作为正式加速度。
- 初始 `b0` 只由机构几何和实测给数量级：旧标定约 100 count/degree，130 PWM 连续 400 ms 约移动 276 count，钢球滚动理论约 120 mm/s²/degree，因此 `b0` 约为 6～7 `(mm/s³)/PWM`，符号由已确认方向决定。最终值必须由一组对称脉冲实测辨识。
- 输出诊断包含速度创新、估计加速度、输入预测贡献和观测器是否可信。长帧间隔或端点约束期间降低观测器可信度，不允许高增益追噪声。

### 3.3 正常运动层（只在观测器可信时）

1. 位置层生成受限目标速度：

   ```text
   v_ref = sign(error) * min(v_max, sqrt(2 * a_stop * abs(error)))
   ```

   该制动距离轨迹会随剩余距离自动降速，不再用大位置 P 长时间积累管姿态。

2. 速度层生成目标加速度：

   ```text
   a_ref = clamp(kv * (v_ref - v_hat), -a_max, +a_max)
   ```

3. 加速度层根据 `a_ref - a_hat` 决定下一次 P60 短脉冲的方向和密度；误差在一档脉冲可分辨范围内时只主动刹车，不继续修姿态。

4. 进入保持必须同时满足位置、速度、估计加速度连续合格；保持时不清空观测器，只停止无意义微动。这样后续小车坡度或加速度变化仍会通过真实球运动重新被观测。

### 3.4 端点/静摩擦混合状态

端点不能交给普通 PID：

1. `PROBE`：当目标明确朝管内、球在端部且连续静止时，以 25 ms 脉冲逐次探测，每次之间主动刹车并等待真实视觉帧；设置最大次数和总时限。
2. `RELEASE_CONFIRM`：只有连续向内位移和/或速度在至少两个真实帧一致后才确认脱离，单帧速度尖峰不算。
3. `CATCH`：确认脱离后立即按本次累计实际 `PWM·ms` 和方向标定系数执行一次连续反向回偿，先快速撤销已积累的执行器姿态，再依据可信视觉状态微调；不得用“速度比峰值下降”单独退出，因为碰到端挡片也会造成相同现象。不使用 P60 编码器位置作为退出条件。
4. `TRACK`：速度和加速度进入正常范围后交给分层轨迹控制。

管内非端点但因静摩擦长期不动时复用较弱、次数更少的 `PROBE`，避免另造一套互相冲突的起动逻辑。

## 4. 参数不靠猜的辨识顺序

恢复闭环前只执行以下一组诊断测试，且每步只改变一个量：

1. 电机零输出静态采集 2 s，确认速度创新、`a_hat` 95% 范围和最长帧间隔。
2. 在端点执行既有 25 ms 有界探测，记录每个实际脉冲的 `PWM·ms`、视觉速度变化和脱离帧；不运行位置闭环。
3. 脱离确认后立即连续偿还累计输入债务并主动刹车；最低回偿量由命令历史和正反方向标定系数确定，视觉只允许追加修正，不能因为端点碰撞造成的速度下降提前取消回偿。P60 计数只用于事后核对余动，不能参与退出。
4. 用日志拟合 `b0`、视觉到动作延迟、一档脉冲造成的加速度变化以及主动刹车后的余动时间。若正反方向差异超过 20%，保存两方向独立执行器标定值，而不是用 PID 补偿机械不对称。

## 5. 逐级验收，未通过不得跳级

| 阶段 | 测试 | 通过条件 |
|---|---|---|
| A | 静态观测器 | 球静止 2 s 时 `a_hat` 不产生持续同向漂移；虚假加速度不足以触发脉冲 |
| B | 单端点脱离 | 连续 5 次均能向管内脱离，不贯穿全管，不超探测时限 |
| C | 单步运动 | `+120→+80`、`-120→-80` 各 5 次，最大超调受限且能稳定在 +/-10 mm |
| D | 任意位置 | 从至少 `-100/-50/0/+50/+100 mm` 初态到多组目标，每组 5 次均稳定 |
| E | 要求 3 | 连续 10 次 `0→+50→-50 mm`，每次总时长 ≤5 s，两目标均满足误差和 250 ms 判稳，不靠一次碰巧穿窗 |
| F | 小车运动 | 先低速直线，再循迹；最后才增加车辆加速度扰动补偿 |

每次保存固件哈希、Maix 构建号、参数、初始球位、目标、原始 20/50 ms 遥测、成功判据和失败原因。失败后先归类为视觉、观测器、端点状态机、轨迹或执行器层，只改对应层。

## 6. 首版保守边界

- 正常运动先以 `v_max=60～80 mm/s`、`a_max=150～250 mm/s²` 为辨识范围；要求 3 通过时间预算后再只提高一个上限。
- 任意时刻只有一个方向脉冲状态；换向前必须主动刹车。
- 帧间隔超过正常上限时立即结束当前驱动脉冲并刹车，不得拿旧速度继续积累姿态。
- 探测状态必须有脉冲次数、总通电时间和总历时三重上限；达到上限仍未看到合理视觉响应则零输出并报告诊断，不自动加大 PWM。
