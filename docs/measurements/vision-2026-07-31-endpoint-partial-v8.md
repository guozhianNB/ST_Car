# MaixCAM2 端部裁切球识别 v8 实测

日期：2026-07-31

## 条件

- 摄像头固定在车架正上方，当前画面左侧为负刻度、右侧为正刻度。
- 三根塑料标定条分别定义 `-100/0/+100 mm`；位置由每帧标定点射影映射得到，不使用旧版固定像素换算。
- 用户确认真实钢球位于画面右端，约 `+120 mm`；两端洞口已用挡板封住，球不会进入不可视区。
- 图像文件：`endpoint-now-raw.jpg`、`endpoint-now-overlay.jpg`；诊断日志：`endpoint-now.log`。

## 原因与修改

右端钢球在图像边缘只呈现部分暗轮廓，并会与端部暗背景合并。旧版按中段完整圆球的宽高比、填充率和面积门限处理，因此会拒绝真实球。

`Vision/cv.py` 的 `2026-07-31-endpoint-partial-background-v8` 只在球心投影位于 `-100/+100 mm` 标定点之外时：

- 放宽部分球的宽高比、暗像素填充率、轮廓宽度和面积；
- 对与端部背景合并的轮廓，用靠近画面外沿的轮廓边缘反推球心；
- 重捕获时降低端部背景变化所需占比；
- 无论是否处于跟踪状态，继续拒绝过小的标记结构伪影。

中段候选条件没有全局放宽，避免把固定结构重新当成球。

## 结果

连续 5 s 采集 26 个 STM32 状态样本：

- 当前真实视觉帧：23 个；
- 有效率：`23 / 26 = 88.5%`；
- 有效位置范围：`+116.48～+121.63 mm`；
- 均值：`+119.52 mm`；
- 标准差：`1.02 mm`。

结论：`VERIFIED`，在本次未开启背部补光的条件下，当前机位右端约 `+120 mm` 的真实球已可稳定识别。左端由于本次实测时球不在左端，仍标记为 `UNVERIFIED`，应在后续球自然到达左端时以相同方法复核；不得仅凭算法对称性写成已验证。

后续条件变化：同日启用 MaixCAM2 `B25/GPIOB25` 背部照明 LED 后，亮度和反光分布改变，v8 的暗光空管背景参考不再可用。v10 已停用该参考并在约 `+55 mm` 处验证稳定；`±120 mm` 端部在亮灯条件下仍需重新复核，不能直接沿用本记录作为亮灯端部结论。
