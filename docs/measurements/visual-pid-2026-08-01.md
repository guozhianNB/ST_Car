# 视觉单环 PID 实测与决策记录（2026-08-01）

状态说明：本文件只记录 2026-08-01 在固定小车、MaixCAM 屏幕预览开启条件下的可复现实测。未明确通过要求 3 的配置一律不得称为“已调好”。原始串口日志位于 `tmp/*.log`。

## 固定测试条件

- 控制器：NUCLEO-G491RE；MaixCAM2 只输出球位置与视觉速度，不使用管子倾角。
- MaixCAM 当前构建：`2026-08-01-velocity-uart-v29-preview30`；此前闭环测试使用 `v28-fast-state`。
- 屏幕：`ENABLE_PREVIEW=True`；2026-08-01 将 `PREVIEW_EVERY_N` 从 15 增至 30，仍保留肉眼预览，但减少显示调用频率。
- P60：正 PWM 使球向负 x 加速；130–140 PWM 用于克服减速箱静摩擦。
- 当前测试均保持车轮不转，结束时电机零输出。

## 已确认经验（避免重复试错）

1. **大步长不能直接靠位置 P 增益提速。** P60 改变的是管子姿态，管子姿态再决定球加速度；从 PWM 到球位置近似三级动态。只用位置/速度 PD 或把加速度反馈关闭，会把姿态能量越积越大，产生端到端极限环。
2. **目标速度限幅必须在 `Ka=0` 时也生效。** 已修改 `control_loops.c`，使有 `Kd` 时始终先生成受限目标速度；但 `Ka=0` 的实测仍明显不稳定，因此正式配置不能据此删掉视觉加速度状态。
3. **原 60 mm/s² 目标加速度过高。** 球刚起动时控制器仍继续加倾角，来不及回收。当前候选值已降为 20 mm/s²；此结论尚未构成最终调参通过。
4. **端点口袋是独立的强非线性。** 2026-08-01 右端实测：从端点静止开始，正向 130 PWM、400 ms 使 P60 相对移动约 +276 counts；总相对位置约 +312 counts 后球才离开端点，视觉在约 100 ms 内从 0 增至约 -80 mm/s。普通低限幅反馈无法及时撤销这段已累积姿态，球会贯穿全管。
5. **端点脱离必须自动检测并立即撤回本次累积动作。** 允许使用“本次命令历史/持续时间”作执行器整形，但正式反馈仍只能来自视觉；不得依赖开机倾角、绝对 P60 中点或软件位置边界。P60 计数只用于本次台架辨识与堵转/调试验证。
6. **调试命令 `stop` 不是主动制动。** `bench_debug.c::StopOutputs()` 调用 `Motor_EmergencyStop()`，会把 P60 STBY 拉低并滑行。连续 140 PWM 后发送 `stop`，编码器仍可因惯性继续移动一百余 counts。需要观察主动短刹效果时，应使用 `pulse 0 500` 保持 STBY 开启并令 TB6612 两输入同高；最终再 `stop` 回到安全零输出。
7. **脉冲密度映射曾在静止低指令下失真。** 当前静止最小脉冲 25 ms，而休止上限 180 ms；例如请求约 20 PWM 时理论休止约 260 ms，却被截短，实际平均作用比请求更强。后续应先修正此线性化问题，再判断低增益是否有效。
8. **保持区必须同时检查位置、速度和加速度。** 只检查位置/速度曾在真实加速度约 100 mm/s² 时错误进入保持；现已加入 `|a| <= 20 mm/s²` 条件。
9. **不要把端点高速值自动判作视觉误框。** 静止端点识别连续稳定在约 +/-125 mm；此前 1190 mm/s 尖峰发生在控制器把球真实甩向端部期间。仍需对非物理速度和长帧间隔做控制侧保护，但不能用过严跳变门限遮蔽真实高速运动。
10. **低速脉冲线性化不能替代未测倾角状态的估计。** 把静止脉冲休止上限从 180 ms 增至 600 ms 后，低指令平均作用不再被明显放大；但 `tmp/test_linearized_plus80.log` 中，球从约 +115.7 mm、目标 +80 mm 出发，10.2 s 内 P60 相对计数仍由 +16 累积到 +608，球反而停在 +125 mm。102 个遥测样本中球位范围为 +115.68～+125.02 mm，15 个被 100 ms 遥测命中的非零 PWM 样本全部为正向。说明本次失败不是休止上限或一次偶然反向脉冲，而是端点约束下初始有效倾角不可观、控制器仍持续积累执行器姿态。
11. **端点时“球不动”不能推出“管子已水平”。** 球被端挡片约束时，在其真正脱离以前，任意大小的同向坡度都可得到几乎相同的位置/速度观测；因此任何连续线性 PID/状态反馈都无法仅凭静止视觉判断还需多少反向管姿态。正式方案必须有视觉触发的有限探测/脱离状态，并在出现连续向内运动后立即转入制动，而不能把端点恢复留给普通 PID。
12. **不得继续直接微分视觉速度作为倾角替代量。** 当前 `aball` 来自 80～250 ms 间隔的速度差分，再乘 0.45 一阶滤波；在上述端点测试中静止附近仍出现 -45.8～+74.0 mm/s²。它多次改变 PID 判断且没有利用已知的实际脉冲输入。后续必须改为带输入预测的状态观测器或经过窗口回归的加速度估计，并记录创新残差、估计加速度和实际累计通电时间。
13. **预览降频后仍不能把单帧视觉速度直接用于起动判据。** `tmp/diagnostic_static_preview30.log` 在 P60 实际输入严格为 0 的 2 s 内记录 42 个不同状态快照，球位只在 +20.16～+20.96 mm 内变化，但视觉速度出现 -18.66～+2.32 mm/s；期间有 1 个 `status=0` 快照，13 个真测量间隔超过 80 ms，最长 122 ms。说明降低屏幕刷新频率保留了预览并略缩短最差间隔，但候选中心亚毫米跳动和短暂失帧仍足以越过旧 8 mm/s 阈值；正式运动确认必须要求连续帧和观测器一致，不能靠单帧速度。
14. **“速度从峰值下降”不能单独作为反向制动完成判据。** `tmp/probe_catch_visual_to_zero.log` 从 +20.82 mm 向 0 探测：第 17 次 25 ms 正向脉冲首次出现可靠位移/速度，第 19 次才确认，此时向内速度已约 31.37 mm/s。旧脚本把 19 次驱动分散地用 10 次反向脉冲补偿；累计实际输入仍为 `uimp=+29250 PWM·ms`、`upos=475 ms`、`uneg=250 ms`，P60 调试计数最终为 +147。球继续加速并到达 -125.13 mm；撞到左端后速度下降被误判为已经制动，最终停在约 -111.6 mm。该版本判据已禁用，不得重试。
15. **脱离后的制动必须快速偿还本次命令历史债务，并增加空间保护。** 探测阶段每次都短刹是为了保持可观测和限制机构能量；但一旦视觉确认脱离，反向动作必须立即连续执行，不能再以约 200 ms 周期逐个补偿。第一版安全基线按累计实际 `PWM·ms` 和已标定的正反方向比例计算一次连续回偿；不得在完成最低回偿前因速度下降而退出，尤其不得在 `|x| > 110 mm` 的端区把减速视为制动证据。正常轨迹还必须在目标前按停车距离进入 CATCH，禁止越过目标后继续驱动。
16. **无位移门禁阈值必须覆盖正式脉冲，并跨短休止保持检测状态。** `tmp/probe_debt_catch_left_v2.log` 中 `-130 PWM` 分散通电 595 ms，但 P60 只在 0/-1 count 抖动，小球保持约 -111.67 mm。操作者肉眼未发现电机堵转迹象，因此当前只能判为“静止负载下 25 ms 负向脉冲未形成有效轴位移”，较可能是每次刚进入起动/齿隙阶段就被主动短刹，不能据此断言机械卡死。旧 `APP_BEAM_STALL_PWM=150` 高于正式脉冲 130～140，确实使无位移故障永远不会触发，且 150 ms 复位窗口短于探测周期；2026-08-01 将阈值改为 120、故障时间 750 ms、无驱动复位窗口 500 ms。恢复方法是先零输出核对，再用同一 PWM 的单次 100 ms 有界脉冲区分“脉宽不足”和真实无响应；不得直接提高 PWM 绕过。

## 暂停实物试参后的方案审查（2026-08-01）

由于连续多轮失败具有相同的端点累积/甩管特征，已按用户要求暂停继续烧录和调增益。当前判断如下：

- 论文中的常规球杆系统多为串级结构：位置外环给出期望管角，快速内环跟踪管角；本项目明确不能读取管角，所以不能把论文的串级 PID 参数直接照搬。
- 本机构在小角度附近可近似为 `PWM → 电机/管姿态变化率 → 球加速度 → 球速度 → 球位置`，是含执行器死区、迟滞和端点约束的三阶以上对象。只用 `位置误差 + 视觉速度 + 速度差分加速度`，但不把实际 PWM 输入纳入估计，会让不可观的初始管姿态与测量噪声直接变成持续电机位移。
- 可借鉴的方向不是更复杂的固定 PID，而是“视觉状态观测 + 分层轨迹 + 端点混合状态”：用已知实际 PWM 预测有效加速度变化，用新视觉位置/速度校正；外层按剩余距离生成限速/限加速度轨迹，内层只追踪期望加速度；端点和静摩擦区用有界探测，视觉确认运动后立即切换制动。
- 相关依据：2021 年 IEEE 实验研究明确把执行器动态、速度不可测、扰动观测和主动阻尼一起处理（[Kim 等，DOI 10.1109/TCSI.2020.3032128](https://doi.org/10.1109/TCSI.2020.3032128)）；ADRC 球杆研究用 ESO 估计并补偿系统总扰动（[Ding 等，2019](https://doi.org/10.1080/21642583.2019.1575297)）；测量噪声下高增益 ESO 会放大噪声，需要限制带宽或采用级联结构（[Łakomy 等，2021](https://arxiv.org/abs/2004.01483)）。这些论文支持“先估状态/扰动，再控制”，不支持继续对带噪速度做高增益差分。

## 恢复实物测试前的唯一实现步骤

先增加纯诊断而不闭环：记录每 5 ms 的实际 P60 命令积分（正/负通电 ms）、脉冲/休止状态，并在每个真实视觉帧上输出观测器的 `x/v/a`、创新残差和帧间隔。随后只做一组有限、对称、可随时停止的视觉激励，辨识“实际脉冲输入 → 有效加速度变化”的符号、延迟和数量级。只有离线回放表明观测器在静止端点不再把 +/-50 mm/s² 噪声当作持续倾角、且对真实起动能在 2～3 帧内确认，才烧录下一版闭环。

### 视觉误检事故与修复

- `VERIFIED`：真实球位于右端、管道已向右倾到机械限位时，旧视觉把图像左端约 `x=9 px` 的固定暗块误认为球并输出约 `-129.9 mm`。这不是坐标符号反转；坐标方向仍为图像右侧 `+x`，`IMAGE_LEFT_POSITION_SIGN=-1.0`。
- 立即 `stop` 后确认零输出，并用 `run +100 100` 的10脉冲受限点动使编码器由约 `-887` 回到 `-874`，退出右倾机械限位。
- MaixCAM2 当时温度约 `56.35 °C`、处理约 `7～10 ms`、约60 FPS，未发现热降频。长时间运行过热仍是风险，但本次长真帧间隔主要来自检测失效，而非相机主循环卡死。
- 部署 `2026-08-01-velocity-uart-v44-endpoint-false-reject`：恢复端点候选尺寸上限 `1.75×`、关闭背景分数对有界模板/光流跟踪的否决，并保留跨场景的尺寸、圆度和时序约束。修复后真实右端球冷启动识别为图像约 `x=279 px`、`+108～114 mm`，没有再跳到左端暗块。

### 控制失败复盘

- `tmp/req3-v44-realball-restored-centering15.log`：恢复原回中参数后，正段进入 `+40 mm`，负段只到约 `-28 mm` 后超时。只改负段提前量撤销点 `-10→-30 mm`。
- `tmp/req3-v44-brake-minus30-repeat17.log`：从 `-45 mm` 回中时球长期静止，速度尖峰反复清空积分记账，但已累加的管姿态偏置未清，最终球突然高速冲向右端；保护在约 `191 mm/s` 时停机。修复为只有同时检测到至少2 mm真实位移和至少10 mm/s速度才确认释放，并在普通回中释放后快速卸坡。
- `tmp/req3-v44-kd4-uart-switch-run20.log` 与 `tmp/req3-v44-stable-start-run21.log`：快速卸坡状态曾错误进入要求3，使 `sreq` 超过 `400 steps/s` 并破坏已通过轨迹。最终增加模式隔离：要求3中禁用普通回中捕获并恢复原积分运动复位逻辑。
- 高频20 ms遥测会占用非阻塞串口队列，模式切换命令可能得不到执行。`tools/req3_chain_probe.py` 现于切换时暂停遥测、停住执行器、恢复正式增益、确认启动后再开遥测；O点起动要求收紧为 `|x|≤8 mm`、`|v|≤4 mm/s` 连续800 ms。

### 最终实物结果

测试条件：小车静止；视觉 v44；正式序列 `Kp/Ki/Kd/Ka=1.2/2.0/2.0/0`；`rate_limit=400 steps/s`；正负内部提前量均70 mm；负段在 `-30 mm` 撤销提前量；最终窗 `-50±10 mm` 且真实帧速度不超过25 mm/s连续250 ms。
